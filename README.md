# ECE-128-Lab-5

## Description
This lab focuses on designing and simulating sequential logic circuits using Verilog, including SR latches, SR flip-flops, D flip-flops, T flip-flops, a 3-bit counter, and a 25 MHz clock divider.

## Simulation
1. Open the project in Vivado.
2. Add the Verilog source files and testbenches.
3. Select the appropriate testbench.
4. Run Behavioral Simulation and observe the waveforms.

## FPGA Implementation
1. Select the design as the top module.
2. Add the Basys 3 constraints file.
3. Run synthesis and implementation.
4. Generate the bitstream and program the board.
